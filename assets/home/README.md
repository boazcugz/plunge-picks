# assets/home
תמונות עמוד הבית (hero, כרטיסים, CTA, OG).

**עודכן — משימת תמונות ריאליסטיות (30.07.2026):** שלושת כרטיסי המסלולים
(`start-with-ice.webp`, `build-your-own.webp`, `buy-complete-system.webp`) הוחלפו
מאיורים לתמונות פוטוריאליסטיות, באותם שמות קובץ ואותם מידות (1200×800) —
אין שינוי נדרש ב-HTML מעבר לעדכון ה-alt. נוסף `home-lifestyle-secondary.webp`
(1400×788) לשימוש בבאנר המשני באזור ה-CTA של הצ'קליסט בעמוד הבית, במקום
שימוש חוזר ב-article-beginners.jpg. hero.jpg בשורש הריפו הוחלף גם הוא לתמונה
פוטוריאליסטית (1920×1080), עדיין דרך רקע CSS ב-.hero2 — אין שינוי בקוד.

קבצי ה-`.png`/`.svg` הישנים בתיקייה הזו (`build-your-own.png/svg` וכו') הם
האיורים הקודמים ואינם מקושרים משום HTML — נשארו כרגע כארכיון, לא נמחקו
במשימה הזו כדי לא לערבב מחיקה עם משימת תמונות.
