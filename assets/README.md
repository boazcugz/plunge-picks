# /assets — PlungeWise brand & image assets

נוצר במשימה **PW-REBRAND-BASE** (26.07.2026). כרגע התיקיות **ריקות בכוונה**.
חבילת התמונות הסופית תיכנס לכאן במשימה הבאה, **PW-BRAND-ASSETS**.

עד אז האתר משתמש ב-**לוגו טקסטואלי בלבד** — `PLUNGEWISE` — ואין שום תלות בקובץ תמונה כדי שהאתר ייראה תקין.

## מבנה

| תיקייה | מה נכנס לשם |
|---|---|
| `assets/brand/` | לוגו, סימן (mark), favicon, לוגו לפוטר, גרסאות רקע כהה/בהיר |
| `assets/home/` | hero, תמונות כרטיסים בעמוד הבית, OG של עמוד הבית |
| `assets/diy/` | תמונות למסלולי ה-DIY ולעמודי DIY & Budget |
| `assets/pinterest/` | פינים מוכנים (1000×1500) ותבניות שלהם |

## כללים לקבצים שייכנסו לכאן

1. שמות קבצים באנגלית, אותיות קטנות, מקפים בלבד. בלי רווחים ובלי עברית.
2. כל תמונה בגודל הסופי שלה — בלי הקטנה בדפדפן.
3. תמונות תוכן: `.jpg` באיכות 80–85. לוגו וסימן: `.svg` אם אפשר, אחרת `.png` שקוף.
4. תמונת קונספט **אינה לוגו**. אין לחתוך ממנה סימן ואין להשתמש בה בהדר.

## נקודת ההחלפה של הלוגו (ל-PW-BRAND-ASSETS)

הלוגו מוגדר בבלוק ה-`<header class="nav2">` בכל אחד מ-24 עמודי ה-HTML, וזהה בית-בית בכולם:

```html
<a class="brand" href="index.html" aria-label="PlungeWise home">
  <svg width="26" height="26" ...></svg>
  <span class="wm">PLUNGE<b>WISE</b></span>
</a>
```

כשתהיה חבילת מותג, מחליפים את ה-`<svg>` בלבד ב-`<img src="assets/brand/…" alt="" width="26" height="26">`
ומשאירים את `<span class="wm">` במקומו כטקסט. כך הלוגו הטקסטואלי ממשיך לשמש כ-Fallback גם אם התמונה לא נטענת.

**אין להחליף את `<span class="wm">` בתמונה.** שם המותג חייב להישאר טקסט אמיתי — בשביל SEO, בשביל קוראי מסך, ובשביל שהאתר לא יישבר כשתמונה לא נטענת.
