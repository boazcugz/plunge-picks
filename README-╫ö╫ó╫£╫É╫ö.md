# PW-BRAND-ASSETS — קבצים להעלאה (גרסה סופית, כולל תיקון ה-hero)

## מה יש כאן
- **24 קבצי HTML** — כולם עודכנו (favicon, סמל בהדר, סמל בפוטר, Open Graph).
- **style.css** — 602 שורות (היו 567). שלושה כללים חדשים בלבד.
- **תיקיית `assets/`** — 46 קבצים, כולל `assets/diy/diy-hero.*` בגרסה המתוקנת.

## איך מעלים ל-GitHub
1. היכנס ל-https://github.com/boazcugz/plunge-picks
2. לחץ **Add file → Upload files**.
3. גרור לחלון את **כל 25 הקבצים** שבתיקייה הראשית כאן (24 קבצי HTML + style.css).
4. גרור **גם את תיקיית `assets` כולה** — GitHub שומר את מבנה התיקיות.
5. תיאור: `PW-BRAND-ASSETS: brand assets, favicon, OG, homepage illustrations, DIY hero`
6. לחץ **Commit changes**. Netlify יעלה תוך דקה-שתיים.

## מה לא נמצא כאן ובכוונה
תיקיית `docs/` — מסמכי העבודה הפנימיים. **הם לא עולים לריפו הציבורי.**

## אחרי ההעלאה
נקה מטמון (Ctrl+F5) כדי לראות את ה-favicon החדש — דפדפנים שומרים favicon בעקשנות.
